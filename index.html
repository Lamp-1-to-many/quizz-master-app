Technical Guides & Documentation

Data Integration: CSV Formatting

To bulk import questions into your bank via the Manage Bank tab, your `.csv` file must perfectly match the internal schema. Use a spreadsheet tool (Excel/Google Sheets) and ensure the top row contains these exact headers:

Subject, Topic, Question Text, Option 1, Option 2, Option 3, Option 4, Option 5, Correct Answer (1-5), Explanation
Formatting Rules:
  • Subject & Topic: Used to dynamically categorize and filter questions.
  • Correct Answer: Must be a numerical value (e.g., type 2 if Option 2 is correct).
Handling Empty Fields:
  • You must provide at least Option 1 and Option 2.
  • Leave Options 3, 4, 5, or Explanations completely blank if they are not required.
